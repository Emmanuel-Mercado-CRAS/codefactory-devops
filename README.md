# CodeFactory Solutions - Transformação DevOps

## Descrição
Este projeto demonstra a implementação de práticas DevOps na empresa fictícia CodeFactory Solutions, incluindo versionamento, containerização e integração contínua.

## Objetivo
Melhorar a colaboração, padronizar o desenvolvimento e automatizar entregas para reduzir erros e atrasos.

## Tecnologias
- Python 3.9
- Flask
- Git e GitHub
- Docker
- GitHub Actions (CI)
